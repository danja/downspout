Create a new plugin Interleaver which will be an unusual effect. It will take two stereo audio input channels and output one stereo output. The input signals will be interleaved with each other, either directly in the time domain or using PVOC. The time domain interleaving may or may note be timed to the fundamental period of one of the input channels. It may or may not use interpolation. How the PVOC interleaving is done is your decision, we are aiming for "interesting" more than "musical". Also you decide on which parameters to expose as controls in the UI and whether or not some kind of graphical display might be appropriate. It should have the Magneto look & feel.
