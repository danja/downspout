## Functionality

T-Mix combines eight separately routable mono inputs into a stereo output.
Every strip provides a pre-fader meter, level fader, constant-power pan, Mute,
and Solo, followed by a stereo master fader.

### Status

New original plugin with deterministic core coverage; host routing and UI
workflow await broader DAW testing.
