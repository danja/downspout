## Functionality

Orchid listens for stable pitched audio, captures a short period-aligned loop,
and holds it against host transport before crossfading back to live input. It is
intended for simple voiced freezes, grid-aligned holds, and instrument-like
loop capture without becoming a sampler.

The UI exposes capture mode, grid, hold length, retrigger behavior, and detector
status so the capture logic remains visible while playing.

### Status

Good fun as a glitch effect.
