Skream will be a new plugin intended to recreate the 2010s sounds of Skrillex and other dubstep artists with the Native Instrument Massive synth screaming timbre, also known as a growl, a talking bass lead and Modern Talking.
There is an existing plugin with source available : /home/danny/github/Scream

We will need to take the DSP from this plugin and approximate the GUI by porting to the DPF framework. Keeping in the style of the other Downspout plugins it is important that the UI isn't too cluttered. Use sliders, knobs etc as you think most suitable. Include a dropdown list of 10 presets offering very different sounds. When a preset is loaded it should modify the controls, which can then be adjusted to taste. Parameters should be modulatable with the Drift plugin. 

Some additional notes below to use as inspiration.

How the Sound is MadeMassive Wavetable: Set the first oscillator to the "Modern Talking" position found in the digital/hybrid section.Warping and Bending: Change the warp mode to a bend or bend-minus option to morph the vowel-like formant shape.Modulation: Tie an LFO or a custom-drawn performer shape directly to the wavetable position and filter cutoff.The Scream Filter: Add a scream filter inside Massive, automating the cutoff and resonance to give the mid-range an aggressive, biting character.Post-Processing: Layer multiband distortion—such as Ohmforce Ohmicide or OTT compression—after the synth to finish the dirty, metallic edge.
Modern Analysis of the TechniqueSound as a Hook: Instead of relying purely on traditional notes or melodies, Skrillex treated raw sound design and vowel-like growls as the main vocal hook of an instrumental drop.Dynamic Contrast: The effectiveness of the scream patch relies heavily on quiet, atmospheric or melodic intros that build tension before dropping into chaotic, distorted bass.Evolution: Modern producers continue to replicate these routing concepts in plugins like Xfer Serum, proving that formants and aggressive wavetable bending remain staples of heavy electronic music.
