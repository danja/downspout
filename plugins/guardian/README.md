# Guardian

Guardian is an output-safety processor for mixing hot with less harsh
distortion. Its default-on input interpolater rebuilds clipped runs as a ramp
between the clean samples on either side, leaving all other samples untouched
by that stage. It also provides bounded look-ahead limiting with attack and
program-dependent release, optional auto drive to a target reduction, a 4x
inter-sample peak guard, variable soft clipping, DC removal, bypass and a live
protection-density meter.
